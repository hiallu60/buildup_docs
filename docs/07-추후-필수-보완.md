# 추후 필수 보완

현재 1차 배포 이후 반드시 진행할 항목만 정리합니다.

1. **HTTPS·도메인** — 암호화된 통신과 고정 API 주소를 제공하도록 도메인과 TLS 인증서를 적용합니다.
2. **프론트 CORS·팀 API 접근 방식** — 앱·웹의 실제 Origin과 팀원 접근 범위를 정하고 임시 IP 허용 방식을 정리합니다.
3. **API 명세·오류 응답 규격** — 요청·응답 DTO, 권한, 상태 코드와 공통 오류 형식을 프론트가 바로 사용할 수준으로 확정합니다.
4. **S3 파일 저장** — 보고서 사진과 첨부파일의 실제 업로드, 조회, 삭제 흐름을 구현합니다.
5. **Refresh Token 보관 방식** — 웹과 앱 환경별로 탈취 위험을 줄이는 안전한 클라이언트 저장 정책을 확정합니다.
6. **로그인·토큰 갱신 요청 제한** — 무차별 로그인 시도와 과도한 Refresh 요청을 막는 Rate Limit을 적용합니다.
7. **운영 비밀정보·서버 접근 권한 관리** — 환경변수, DB 자격 증명, SSH 키와 운영 권한을 최소 인원·최소 권한으로 관리합니다.
8. **핵심 API 자동 테스트** — 인증, 현장 권한, 승인, 자재 상태 변경의 회귀 테스트를 자동 실행합니다.
9. **서버 로그·장애 알림** — 애플리케이션 오류와 자원 이상을 수집하고 담당자에게 알리는 체계를 마련합니다.
10. **RDS 백업·배포 롤백** — 복구 가능한 백업 기준과 문제 발생 시 이전 버전으로 되돌리는 절차를 문서화하고 검증합니다.
